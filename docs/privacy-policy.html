Privacy Policy

Last updated: June 2025  ·  MaxAI Engine  ·  Developer: mahendraplus

MaxAI Engine is an on-device AI platform for Android. This Privacy Policy explains how the app handles your data. By using MaxAI Engine, you agree to this policy.

1. Data Collection

MaxAI Engine does not collect, store, or transmit any personal data to any external server. The app operates fully offline and on-device. All data remains on your device only.

2. Data Stored Locally

The following data is stored only on your device and is never shared:

  • Chat history and conversations
  • Downloaded AI model files (GGUF / LiteRT LM)
  • App settings and preferences
  • Local API server configuration

3. Permissions

MaxAI Engine may request the following Android permissions:

  • Storage: To read and manage local AI model files
  • Local Network / Internet: To run the local API server on your device's WiFi network only — no external connections are made
  • Vibration: For haptic feedback in the user interface

No permission is used to collect or share personal data externally.

4. Third-Party Services

MaxAI Engine does not include any third-party analytics, advertising SDKs, crash reporting services, or tracking libraries. No data is shared with any third party.

5. AI Models

MaxAI Engine is a runtime platform only. It does not include any AI models by default. Users load their own models. The app does not review, log, or transmit any AI model inputs or outputs.

6. Children's Privacy

MaxAI Engine is not directed at children under the age of 13. We do not knowingly collect any information from children.

7. Data Security

Since all data remains on your local device, your privacy is protected by your device's own security features. We recommend using a screen lock and keeping your device software up to date.

8. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated date. Continued use of the app after changes means you accept the updated policy.
