Frequently Asked Questions

Which AI models are supported?
MaxAI Engine supports GGUF and LiteRT LM (.tflite) format models. You can download compatible models from HuggingFace and load them locally.

Does the app require internet?
No. MaxAI runs completely offline. Internet is only needed to download models initially. All inference happens on-device.

How do I enable GPU acceleration?
Go to Settings → Inference → Enable GPU Acceleration. This uses your device's GPU for faster inference. Not supported on all devices.

How does the local API server work?
MaxAI hosts a REST API server on your local network. Access it from any device on the same WiFi using the IP address shown in the app. It uses an OpenAI-compatible API format.

The app crashes when loading a model. What should I do?
Try a smaller quantized model (Q4 or Q5). Large models may exceed your device RAM. Also re-download the model file to rule out corruption.
